version is the Claude Doc "M.U.L.E. Successor: Game Design Concept"
(https://claude.ai/artifact/REQjsJ2RduQg1vVxrdXjw7). Exported 2026-10-21.

If the two disagree, the Claude Doc wins until it stops being maintained. Once
work moves to another account that can't open the doc, these files become the
design source: edit them here and keep them current.
