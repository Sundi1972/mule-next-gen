  - Measured: `git worktree add` + a subagent `cd …/ws4-pr1-e2e && git status` → "a worktree-isolated session's git
    operations must target its own worktree".
  - So: check out each PR sub-branch IN `.claude/worktrees/ws4-table`, and run one writing agent at a time.
  - Shell commands with `$VAR`, `$(…)`, loops or `{ …; }` around git get refused too. Use plain commands.

  (the PM). Don't work around it; route merges through the PM until Heiko types the rule into the session.

  It used to look in `/opt/pw-browsers` and failed.

  get little done in development, and month-2 phases often run their full scaled length. That is expected (AM-2),
  not a stall.

  Never add retries.

  fixture WS4 writes needs them once it lands. WS3 already edited `apps/web/test/derive.test.ts::view()`.
